# midterm-ppt 이미지 에셋 (Google Flow 프롬프트)

`slides/midterm-ppt.html` (PPT풍 세련된 버전)에서 쓸 사진 3장입니다. 아래 프롬프트로 Google Flow에서 생성해 **지정된 파일명 그대로** `slides/assets/midterm-ppt/img/`에 저장해주세요. 넣기 전까지는 CSS 그라디언트 플레이스홀더로 대체되어 레이아웃이 깨지지 않습니다.

공통 주의사항:
- 실제 브랜드 로고/워드마크(Gucci, SSENSE 등)가 이미지에 나타나지 않도록 "no visible logos or brand names" 를 프롬프트 끝에 유지해주세요.
- 인물 얼굴이 크게 나오는 구도는 피하고, 질감·실루엣·디테일 중심으로 요청했습니다.
