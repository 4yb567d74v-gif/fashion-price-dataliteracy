# midterm-spotify 이미지 에셋 (Google Flow 프롬프트)

`slides/midterm-spotify.html` (DESIGN.md 기반 Spotify풍 버전)에서 쓸 사진 3장입니다. PPT풍 버전과 톤이 완전히 달라 별도 프롬프트를 썼습니다. 지정된 파일명 그대로 `slides/assets/midterm-spotify/img/`에 저장해주세요.

공통 주의사항:
- 실제 브랜드 로고/워드마크가 보이지 않도록 "no visible logos or brand names" 를 유지했습니다.
- Spotify DESIGN.md 팔레트: 근흑색 배경(#121212–#1f1f1f) + 그린(#1ed760) 단일 포인트. 이미지 자체는 거의 무채색(achromatic)으로 요청하고, 그린은 UI가 얹히는 걸 가정해 비워뒀습니다.
